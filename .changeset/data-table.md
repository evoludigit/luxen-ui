New `<l-data-table>`, wrapped around a `.l-table` to add what HTML lacks, documented on the table page. Give sortable headers a `data-key`: activating one fires `sort-change` with the next sort, and the page sorts its rows and renders `aria-sort` from it. Add `selectable` and leave the header's `data-select` cell empty: a header checkbox appears once the script runs, with a mixed state, Shift with a click or with Space selects a range, and a selected row stays selected while it is off the table. `selection-change` reports the selected values; `rowSelection`, `allMatching` and `clearSelection()` let the page drive it. The sort and the selection travel in TanStack Table's state shapes (`SortingState`, `RowSelectionState`), without depending on it. Add `navigable`, off by default, for keyboard work through a list: the body is one tab stop (the row last reached, then its own controls), ↑ and ↓ move between rows (Home, End, Page Up and Page Down too), Space toggles the focused row, Shift with a move key selects a run that shrinks when moving back, Ctrl or Cmd with A selects the page's rows, Escape clears a checkbox selection, and Enter follows the row link, keeping Ctrl, Cmd or Shift; a removed focused row hands focus to its neighbour, and rows only, so the table keeps table semantics. The element renders nothing else, so the page keeps rendering every row.
